# 根据 Wiki 线索恢复本地引用解析

2026-10-18。此结果修正前一轮“用 Wiki 文本填空”的方向：Wiki 只用于确认待追踪名称，实际导出只读取本地游戏表，不读取 Wiki 缓存或审核映射。

## 结果

[修正后的纯本地导出](../../logs/catalog_probe_20261018/local_catalog_resolved.json) 包含原有 54 名五星角色、65 把五星武器，及 1,539 条技能显示记录、613 条 Buff 显示记录、135 条术语。这些数字包含等级/椎体分支及附属效果，不是独立技能数量。

此前 72 条技能、4 条 Buff 说明中的占位符，现在全部通过本地关联解析。原有关联图中的 100 个不同动态表达式都有本地 ShareLimit 记录，所有被导出 grade 分支均找到显示名称。导出器不依赖 `wiki_reference_overrides.json`。

可复现：

```powershell
python tools/gf2-role/export_local_catalog.py --output logs/catalog_probe_20261018/local_catalog_resolved.json
```

## 此前遗漏的表关系

原先将 `0:-1,组ID,序号` 错当作具体 Buff ID 与等级，因而找不到显示记录。正确的数据链是：

```text
BattleSkillDisplayData / BattleBuffPerformData 的引用字符串
  -> BuffShareLimitByGroupData[组ID].f2：ShareLimit 行 ID
  -> BuffShareLimitData[行ID].f4：逗号分隔的 grade ID
  -> BuffShareLimitData[行ID].f5：按相同顺序排列的 Buff 列表
  -> 对应 grade 的分号列表中，选择从 1 开始的指定槽位
  -> BattleBuffPerformData[具体BuffID]
  -> LangPackageTableCnData：本地名称与说明
```

列表成员可能附带 `-N` 后缀。程序提取 Buff ID，并保留原始成员及 `suffixArgument`；没有把后缀解释为已证实的初始层数、等级或上限算法。

`0:340602,1` 还暴露了带附加参数的直接引用格式；其 ID `340602` 的本地显示行一直存在，名称为“强酸倾压”，无需用 Wiki 代替本地内容。

底层 `FormatSkillDesc` 的 C# 算法没有恢复。上述槽位与分支解析由本地记录的结构、一一对应关系和实际显示内容交叉验证支持。客户端 Lua 的调用证据进一步确认描述格式化确实传入预览椎体详情，详见 [引用语义研究](LOCAL_REFERENCE_SEMANTICS.md)。

## 三个纯本地例子

### 校音

黛烟“清商和鸣”的引用为 `0:-1,103209,1`。

`BuffShareLimitByGroupData[103209].f2=103209`；对应 ShareLimit 行在 grade `103201` 的 f5 项是 `10320981;10320991-10`。第 1 槽位得到 `10320981`，本地 Buff 显示行和语言表给出：

> 校音：暴击率提高3%，暴击伤害提高3%，至多叠加10层。主动攻击后获得6格移动追加。增益不可驱散。

同一列表的第二项是另一条“永久校音”记录；它和“校音”不能混为一个 Buff。槽位参数与 grade 也是两个不同维度。

### 细胞共鸣的升级版本

`0:-1,10850701,1` 指向按 grade 选择的 Buff：

| grade | 具体本地显示 ID | 本地说明 |
|---|---:|---|
| `108501`（0阶） | `10850701` | 攻击力提高3%，制胜技能伤害系数提高5%，至多5层；增益不可驱散 |
| `108502`～`108507` | `10850702` | 攻击力提高5%，制胜技能伤害系数提高10%，至多8层；增益不可驱散 |

因此只导出基础 Buff、或把 Wiki 的某个版本直接填入所有技能等级，都会丢失培养状态差异。

### 拟合共鸣

`0:-1,10770800,1`：

| grade | 具体本地显示 ID | 本地效果 |
|---|---:|---|
| `107701`（0阶） | `107708004` | 周围半径5格，40%攻击力的浊刻伤害与1点稳态伤害，每回合至多10次 |
| `107702`～`107707` | `107708005` | 60%攻击力的浊刻伤害与1点稳态伤害，另施加防御降低II，持续2回合，每回合至多10次 |

这两个版本都来自本地原文，不能统一覆盖成 Wiki 中展示的60%版本。

## 如何使用导出结果

- 普通引用保留本地表名、ID 和字段路径。
- 动态引用的 `references[].variants` 保存每个 `gradeId` 对应的具体 Buff ID、名称和完整解析路径；效果说明在顶层 `buffs` 中按 ID 查询。
- `gradeDescriptions` 给出各 grade 的名称替换结果。技能自身是否已解锁还应依据角色 `grades` 数据判断，不能把每条文本分支都当作可用技能。
- 顶层 `description` 采用首个可用本地 grade 的名称；需要准确展示玩家状态时，应使用明确 grade 的分支。
- 所有表的绝对路径和 SHA-256 均保存在 `sources`。没有 Wiki 字段或 Wiki 来源文本。

## 剩余边界

- 针的 `10852002` 有本地运行配置，但没有独立显示行；原样保留为内部技能，不凭空补说明。
- `10372002`、`10732002`、`10852004` 已由本地运行表确认指向显示 ID `10000` 的空技能占位项。
- 索普 `0:107608012` 仍无显示名称，但对应索引未被当前正文或升级说明使用，不产生文字缺口。
- 基础属性、成长配置与最终面板换算仍是另一个问题，本次不将其宣称为已还原。
