## 🚀 快速开始

### 1. 安装证书

首次使用需要安装 mitmproxy 证书：

- 点击左侧的「安装证书」按钮
- 在打开的网页中，选择对应的操作系统（Windows/macOS/Linux）
- 下载并按照页面指引安装证书
- **重要**：安装后将证书设置为"受信任的根证书颁发机构"

### 2. 获取抽卡记录

**顺序很重要**：工具必须先"抓到"一次游戏发出的抽卡请求，点「更新记录」才有东西可以重放。

1. 先打开本工具（它会自动启动内置代理、装上证书）
2. 打开游戏，进入「招募 → 访问详情」页面（进入这一页才会发出抽卡请求）
3. 回到工具，界面上方的状态栏会变成「捕获：已捕获 xx:xx:xx」
4. 这时再点「更新记录」

界面右上角点「日志」会弹出一个小窗口，运行状态都在里面：

| 显示 | 含义 |
|------|------|
| `代理：运行中 127.0.0.1:8080` | 内置代理在跑，游戏请求会被捕获 |
| `代理：未启动` | 代理没起来，请重启工具（否则什么也抓不到） |
| `捕获：尚未捕获...` | 还没抓到游戏请求，按上面的顺序进一次「招募 · 访问详情」页面 |
| `捕获：已捕获 12:03:41` | 可以点「更新记录」了；括号里是这次捕获距现在多久 |
| `日志文件` | 当前日志文件的完整路径 |

窗口里的「打开日志文件」会用系统默认程序（一般是记事本）直接打开 `logs/app.log`，
报障时把里面的内容发出来即可。抓到的请求里含 Authorization，**关闭软件时会自动清除**。

支持五个池子：角色池、武器池、常驻池、自选角色池、自选武器池。

### 3. 导入/导出记录

**导出记录：**
1. 在输入框中设置一个 ID（例如：`player1`）
2. 点击「导出记录」按钮
3. 记录会保存在程序目录的 `records` 文件夹中

**导入记录：**
1. 在输入框中输入之前导出的 ID
2. 点击「导入记录」按钮
3. 记录会加载到当前界面

### 4. 检查更新

- 点击「检查更新」按钮可查看是否有新版本
- 如有更新，可跳转到 GitHub 下载

## 📱 安卓版 0.1.4

**只要一台 64 位 ARM 安卓手机（Android 7.0+）**：支持官服和B服，不需要电脑、root、证书或 VPN。

1. 装 `gf2gacha_XKL_android.apk`（首次会提示「未知来源」，允许即可）
2. 打开 App → `添加账号` → 选择官服 / B服 → 短信验证码或账号密码登录
   （凭证与记录仅存本机，登录请求直接发送到官方服务；B服如需安全验证，会在应用内打开验证窗口）
3. 之后直接进抽卡页：`管理账号` 可多账号切换/删除；`刷新` 在令牌失效时先询问是否发送验证码，确认并登录后继续刷新
4. `分享` 出竖版长图，可直接发微信 / QQ / 存相册；标题右边的 `检查更新` 用来更新版本

- 源码与实现说明：[`XKL_android/README.md`](XKL_android/README.md)
- 接口协议（登录、签名、分页，逆向自官方客户端）：[`GF2_SMS_LOGIN_PROTOCOL.md`](GF2_SMS_LOGIN_PROTOCOL.md)
- 已知限制：令牌是**单会话**的 —— 同一账号在游戏内或别处再登录一次，旧令牌立刻作废，App 会提示重新收码（记录不会丢）；
  官方记录接口只保留一段时间的记录，所以本地记录**只增不减**（按 fakeId 合并，和 PC 版同一套算法）。

## 🔄 版本与更新

| 客户端 | 本地版本 | 远端检查地址 | 安装包 |
|---|---|---|---|
| PC | `version.json`（随包分发） | `https://r2.gf2gacha-xkl.uk/version.json` | `gf2gacha_XKL.zip` |
| 安卓 | 读 APK 的 `versionName` | `https://r2.gf2gacha-xkl.uk/version_android.json` | `gf2gacha_XKL_android.apk`（固定文件名） |

发版用发布助手一条命令搞定（自动算 sha256 / size，避免手工算错）：

```powershell
# PC 版
python tools\make_release.py --version 1.1.6 --notes "这次改了什么"
# 安卓版（先改 XKL_android/app/build.gradle.kts 的 versionCode/versionName 并 assembleRelease）
python tools\make_release.py --android --version 0.1.0 --notes "这次改了什么"
```

**上传顺序：先传包（zip / apk），最后传 json** —— 反了会让用户读到新版本号却下不到包。

## ⚠️ 注意事项

1. **程序单实例运行**：不要重复打开程序，否则可能导致代理冲突

2. **证书安装**：
   - 证书必须安装到"受信任的根证书颁发机构"

3. **网络要求**：
   - 需要保持网络连接
   - 安卓版同理；它自带「检查更新」，更新包会先校验 sha256 再交给系统安装器

4. **记录管理**：
   - 导出记录会合并已存在的同 ID 记录
   - 建议定期导出备份抽卡记录

## 🔧 常见问题

**Q: 点击「更新记录」立刻提示失败？**
A: 说明本地还没有抓到游戏请求（状态栏会显示「尚未捕获」）。请先打开游戏并进入
「招募 → 访问详情」页面，等状态栏变成「已捕获」，再点「更新记录」。

**Q: 提示接口返回错误 / token 过期？**
A: 抓到的请求太旧了，在游戏里重新打开一次「招募 → 访问详情」页面刷新一下再点更新即可。

**Q: 状态栏一直显示「代理：未启动」？**
A: 内置代理没起来（端口被占用或被杀软拦截）。先看 `logs/app.log` 的报错，重启工具再试。

**Q: 重复打开程序会怎样？**
A: 程序会提示已运行并自动退出，这是正常行为。

**Q: 安卓版要装证书或者开 VPN 吗？**
A: 都不要。安卓版是模拟官方客户端的「手机号 + 短信验证码」登录去调官方接口，不走抓包，所以不需要代理和证书。

**Q: 安卓版提示令牌失效 / 要重新收验证码？**
A: 令牌是单会话的：同一账号在游戏内或别处登录过，旧令牌立刻作废。按提示重新收码即可，本地记录不会丢。
