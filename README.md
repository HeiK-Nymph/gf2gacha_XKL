## 🚀 快速开始

### 1. 安装证书

首次使用需要安装 mitmproxy 证书：

- 点击左侧的「安装证书」按钮
- 在打开的网页中，选择对应的操作系统（Windows/macOS/Linux）
- 下载并按照页面指引安装证书
- **重要**：安装后将证书设置为"受信任的根证书颁发机构"

### 2. 获取抽卡记录

**顺序很重要**：工具必须先"抓到"一次游戏发出的抽卡请求，点「更新记录」才有东西可以重放。

1. 先打开本工具，再打开游戏（工具会自动启动内置代理；证书安装后会自动接管系统代理）
2. 打开游戏，进入「招募 → 访问详情」页面（进入这一页才会发出抽卡请求）
3. 回到工具，界面上方的状态栏会变成「捕获：已捕获 xx:xx:xx」
4. 这时再点「更新记录」

界面右上角点「公告」可以查看最新公告；新公告会在应用打开时检查并自动弹出，
公告清单在本机缓存 10 分钟，短时间内重新打开不会重复请求 R2；也可以随时点按钮强制刷新。

界面右上角点「日志」会弹出一个小窗口，运行状态都在里面：

| 显示 | 含义 |
|------|------|
| `代理：运行中（仅解密抽卡接口） 127.0.0.1:8080` | 抽卡接口被解密抓取，其余流量由代理原样透传，照常上网 |
| `代理：未启动` | 代理没起来，请重启工具（否则什么也抓不到） |
| `代理：已启动，系统代理未接管` | 证书尚未安装；点「安装证书」后会自动接管系统代理 |
| `捕获：尚未捕获...` | 还没抓到游戏请求，按上面的顺序进一次「招募 · 访问详情」页面 |
| `捕获：已捕获 12:03:41` | 可以点「更新记录」了；括号里是这次捕获距现在多久 |
| `日志文件` | 当前日志文件的完整路径 |

桌面端会把系统代理临时指向本机 mitmproxy，但 mitmproxy 只解密 `gf2-gacha-record.sunborngame.com`，其他流量一律原样透传（不解密、不要求证书），因此开着工具时其他网站照常可用。主程序异常退出时，独立看门狗进程会恢复原来的系统代理设置；证书未安装时也不会接管系统代理。新版启动时还会自动关闭旧版遗留的失效 `127.0.0.1:8080-8179` 全局代理。

程序自身的检查更新、公告和 R2 数据请求都固定直连，不依赖内置 mitmproxy；检查更新也不会临时关闭或重新开启系统代理。接管系统代理时会保留用户原有的绕过列表，并追加本机直连规则。

> 注意：游戏进程只在启动时读取一次系统代理，所以务必**先开本工具、再开游戏**；已经开着游戏再去开工具，通常要重启游戏才能抓到请求。

窗口里的「打开日志文件」会用系统默认程序（一般是记事本）直接打开 `logs/app.log`，
报障时把里面的内容发出来即可。抓到的请求里含 Authorization，**关闭软件时会自动清除**。

支持五个池子：角色池、武器池、常驻池、自选角色池、自选武器池。

### 3. 导入/导出记录

**导出记录：**
1. 在输入框中设置一个 ID（例如：`player1`）
2. 点击「导出记录」按钮
3. 记录会保存在程序目录的 `records` 文件夹中

**导入记录：**
1. 在输入框中输入之前导出的 ID
2. 点击「导入记录」按钮
3. 记录会加载到当前界面

### 4. 检查更新

- 点击「检查更新」按钮可查看是否有新版本
- 如有更新，可跳转到 GitHub 下载

## 📱 安卓版 0.1.9

**只要一台 64 位 ARM 安卓手机（Android 7.0+）**：支持官服和B服，不需要电脑、root、证书或 VPN。

1. 装 `gf2gacha_XKL_android.apk`（首次会提示「未知来源」，允许即可）
2. 打开 App → `添加账号` → 选择官服 / B服 → 短信验证码或账号密码登录
   （官服账号密码支持**手机号或邮箱**；凭证与记录仅存本机，登录请求直接发送到官方服务；B服如需安全验证，会在应用内打开验证窗口）
3. 之后直接进抽卡页：`管理账号` 可多账号切换/删除；`刷新` 在令牌失效时先询问是否发送验证码，确认并登录后继续刷新
4. `分享` 出竖版长图，可直接发微信 / QQ / 存相册；标题右边的 `检查更新` 用来更新版本

- 源码与实现说明：[`XKL_android/README.md`](XKL_android/README.md)
- 接口协议（登录、签名、分页，逆向自官方客户端）：[`GF2_SMS_LOGIN_PROTOCOL.md`](GF2_SMS_LOGIN_PROTOCOL.md)
- 已知限制：令牌是**单会话**的 —— 同一账号在游戏内或别处再登录一次，旧令牌立刻作废，App 会提示重新收码（记录不会丢）；
  官方记录接口只保留一段时间的记录，所以本地记录**只增不减**（按 fakeId 合并，和 PC 版同一套算法）。

## 🔄 版本与更新

| 客户端 | 本地版本 | 远端检查地址 | 安装包 |
|---|---|---|---|
| PC | `version.json`（随包分发） | `https://r2.gf2gacha-xkl.uk/version.json` | `gf2gacha_XKL.zip` |
| 安卓 | 读 APK 的 `versionName` | `https://r2.gf2gacha-xkl.uk/version_android.json` | `gf2gacha_XKL_android.apk`（固定文件名） |

发版用发布助手一条命令搞定（自动算 sha256 / size，避免手工算错）：

```powershell
# PC 版
python tools\make_release.py --version 1.1.10 --notes "这次改了什么"
# 安卓版（先改 XKL_android/app/build.gradle.kts 的 versionCode/versionName 并 assembleRelease）
python tools\make_release.py --android --version 0.1.9 --notes "这次改了什么"
```

**上传顺序：先传包（zip / apk），最后传 json** —— 反了会让用户读到新版本号却下不到包。

正式发布必须完成以下步骤，R2 和 GitHub Releases 缺一不可：

0. 先跑 `python tools/check_sensitive.py`（会扫 git 已跟踪文件里的 JWT / 私钥 / access_token / API key / 手机号），
   确认没有真实凭证被跟踪。`json/latest_request.json`（抓包产物，含游戏 `Authorization`）必须保持未跟踪状态，
   不要 `git add -f` 它；测试用的真实账号、记录、证书、`.runtime/`、`localdata/` 也都不进 git。
1. 修改 `version.json` 的版本号，同步更新 README 和 `XKL_site/src/data/releases.js` 的兜底信息。
2. 重新构建前端 `frontend/dist`，再运行 PyInstaller 生成 `dist/gf2gacha_XKL`。
3. 运行发布前测试，包括真实冻结版 EXE 启动验证。
4. 执行 `make_release.py` 生成 ZIP、`version.json` 和 SHA256。
5. 提交发布改动，创建并推送 `vX.Y.Z` 标签。
6. 上传 R2：先传安装包，最后传版本清单；随后检查公网版本、文件大小和 SHA256。
7. 在 GitHub 创建同一标签的 Release，标题使用「夏克里助手 vX.Y.Z」，
   上传桌面端 ZIP 和 `SHA256SUMS.txt`；安卓包只在安卓版本发生变化时上传。
8. GitHub Release 发布后再检查 R2 与 GitHub 两处下载入口均可用。

本地测试构建统一放在 `test/`，该目录已加入 `.gitignore`：

```text
test/
├── desktop/gf2gacha_XKL/       # 桌面端测试目录，直接运行 gf2gacha_XKL.exe
└── android/gf2gacha_XKL_test.apk  # 安卓 debug 测试包
```

以后重新构建测试版也覆盖到这两个位置，不再散落在 `dist/`、`release/` 或安卓构建输出目录。

## ⚠️ 注意事项

1. **程序单实例运行**：不要重复打开程序，否则可能导致代理冲突

2. **证书安装**：
   - 证书必须安装到"受信任的根证书颁发机构"

3. **网络要求**：
   - 需要保持网络连接
   - 安卓版同理；它自带「检查更新」，更新包会先校验 sha256 再交给系统安装器

4. **记录管理**：
   - 导出记录会合并已存在的同 ID 记录
   - 建议定期导出备份抽卡记录

## 🔧 常见问题

**Q: 点击「更新记录」立刻提示失败？**
A: 说明本地还没有抓到游戏请求（状态栏会显示「尚未捕获」）。请先打开游戏并进入
「招募 → 访问详情」页面，等状态栏变成「已捕获」，再点「更新记录」。

**Q: 提示接口返回错误 / token 过期？**
A: 抓到的请求太旧了，在游戏里重新打开一次「招募 → 访问详情」页面刷新一下再点更新即可。

**Q: 状态栏一直显示「代理：未启动」？**
A: 内置代理没起来（端口被占用或被杀软拦截）。先看 `logs/app.log` 的报错，重启工具再试。

**Q: 重复打开程序会怎样？**
A: 程序会提示已运行并自动退出，这是正常行为。

**Q: 安卓版要装证书或者开 VPN 吗？**
A: 都不要。安卓版是模拟官方客户端的「手机号 + 短信验证码」登录去调官方接口，不走抓包，所以不需要代理和证书。

**Q: 安卓版提示令牌失效 / 要重新收验证码？**
A: 令牌是单会话的：同一账号在游戏内或别处登录过，旧令牌立刻作废。按提示重新收码即可，本地记录不会丢。
