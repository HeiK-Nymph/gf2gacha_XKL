# 刷新与小程序导出续登验证

验证版本：0.1.2（versionCode 10），MuMu Android 12，2026-10-16。

## 行为

- 无账号时停留在抽卡页；刷新和导出均提示添加账号，用户确认后才进入登录页。
- 导出的过期判据与刷新一致：记录接口返回 `token err` 才进入续登；账号接口返回 UID 不代表凭证未过期。
- 点「导出到小程序」当下就核验：过期直接进续登确认，不再先弹说明框；核验通过后才弹「复制」。
- 凭证为空或官方返回凭证失效时，刷新与导出共用发送验证码确认框。
- 取消不发送验证码、不清除抽卡缓存、不跳转登录页。
- 确认发码后在当前页输入验证码；登录 UID 一致才更新凭证并继续刷新或导出。
- 普通网络错误不进入续登；核验时切换账号不复制原账号钥匙。

## 已完成

- `:app:assembleRelease :app:assembleReleaseAndroidTest` 构建通过，MuMu 同版本覆盖安装成功。
- 协议及过期识别测试 7 项通过，包括 HTTP 401、英文 token 错误、中文凭证过期及普通网络错误区分。
- `verifyReauth=true` 界面测试 8 项通过：无账号、过期无缓存、过期有缓存、缺少手机号，分别验证刷新和导出。
- 界面测试在首次 onResume 前替换为临时目录中的 AccountStore；只点取消，检查确认按钮、续登锁和缓存保留，最后删除临时目录。

运行方法见 [README](../README.md) 的真机测试命令，可用 `adb -s 127.0.0.1:16416` 指定 MuMu。
