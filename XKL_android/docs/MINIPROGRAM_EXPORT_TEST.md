# 小程序钥匙导出真机验证

日期：2026-10-16。

## 实现范围

- 主页增加「导出到小程序」，按下即先用刷新同一条记录接口核验凭证没过期（过期先续登），通过后才弹说明框，点「复制」只写剪贴板不再发请求。
- 核验通过后再调用官方账号接口核对 UID。
- 格式为 `XKL1.` 加 Base64URL 编码，UTF-8 JSON 仅含 `version`、`uid`、`credential`。
- 不导出手机号、密码、本地抽卡记录，不新建登录、不自动发送短信。
- 核验期间账号或凭证变更时不复制旧钥匙。
- 钥匙不写入文件或日志，剪贴板标记为敏感内容。

## 构建与安装

已完成 release 构建及签名校验，在 USB 手机上执行 `adb install -r` 成功。
仍使用原来的 `versionName=0.1.1`、`versionCode=9`，签名未变，没有卸载原应用或清除账号数据。
安装后仍能打开已有账号及抽卡记录。

## 验证结果

真机运行 6 项协议测试，全部通过：

1. 导出结果与小程序协议示例逐字一致。
2. UTF-8 往返、Base64URL 无填充、字段白名单正确。
3. 非法 UID 拒绝。
4. 空凭证和换行注入拒绝。
5. 4096 字符长度边界正确。
6. 剪贴板敏感标记正确。

实际操作验证了主页入口、按下导出即核验、说明弹窗和「复制」。
另用设备内存比对确认：实际剪贴板钥匙的 UID、凭证与当前账号完全相同，敏感标记为真。
测试不打印钥匙或真实凭证，不将它们传回电脑。

测试入口在 `app/src/androidTest/`，默认仅测试固定样例。
可选 `-e verifyClipboard true` 仅用于点击真实导出后的内存比对，不会修改剪贴板。

本次未自动操作手机微信，也未把手机剪贴板钥匙发送给其他人。
小程序的真实云端导入链路已在 `XKL_WeChat/docs/IMPORT_INCREMENT_TEST.md` 单独验证。
